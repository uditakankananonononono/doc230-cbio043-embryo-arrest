# CBIO043 "Digital Embryo: Multi-Omic Arrest Prediction" - preregistration (before any model scored)
Label: partial. Only a normalized TRANSCRIPTOME matrix (genes + transposable elements) is public and CPU-feasible; no matched proteome/methylome, so "multi-omic" is not tested. Replication-style benchmark, no novelty claim. NOT an extension of mega27-14-digital-embryo (that repo is a Drosophila simulation study).
Data: normalized expression matrix from PLOS Biol 3001682 (figshare 19775992, Data S2): 1,027 samples = 30 arrested human IVF embryos (incl. 3+ resveratrol-treated, Type I/II/III/R) + controls from reanalysed public datasets (oocyte/zygote/2C/4C/8C/morula/blastocyst and E3-E7 embryonic-stage cells).
Up-front confound (stated before modelling): arrested embryos come from one lab/protocol, controls from other datasets, so arrest is confounded with source/batch. D3 is a control for this.
Models: L2 logistic regression on log expression of top-variance genes (default 2,000), standardized in-fold. Stratified 5-fold CV repeated 3 times. Metric AUROC (AUPRC reported).
Gates: D2 AUROC >= 0.90 for arrested vs cleavage-stage controls (2C, 4C, 8C, E3). D3 batch control: AUROC for "E3 (Petropoulos-type) vs 8C (other source), same biological stage" must be reported; if it is >= the D2 AUROC - 0.05, the D2 result is labeled batch-dominated.
Directions: D1 data stats + source structure; D2 arrested vs cleavage-stage controls; D3 same-stage cross-source control (E3 vs 8C/4C); D4 arrest type (I vs II vs III) macro-F1, leave-one-out, small n; D5 pre-registered ZGA/maternal-clearance gene score (DUX4, ZSCAN4, BTG4, ZNF280A, LEUTX, TPRX1, KLF17, DPPA3) AUROC; D6 feature-count sensitivity (50/500/2000/5000 genes); D7 label-shuffle control; D8 feature class (protein_coding vs other transcript_type) AUROC; D9 resveratrol-treated vs untreated arrested separation; D10 arrested vs all non-arrested including blastocysts (stage-mismatched; expected inflated, reported as such).
Not run: proteome/epigenome integration; raw-read realignment.
